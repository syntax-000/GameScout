# Security policy

## Supported versions

Security updates currently target the latest `0.1.x` version on the default branch.

## Reporting a vulnerability

Please do not disclose suspected vulnerabilities, leaked credentials, or exploit details in a public
issue. Use the repository's **Security** tab and select **Report a vulnerability** to start a private
security advisory.

Include the affected version, reproduction steps, expected impact, and any suggested mitigation. Do
not include real Steam API keys, personal data, or unrelated secrets in the report. Reports will be
reviewed before any public disclosure or release notes are prepared.

If private vulnerability reporting is unavailable, open a public issue containing no sensitive
details and ask the maintainer to provide a private reporting channel.
